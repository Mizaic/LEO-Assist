# Package D -- Neighbourhood Diversion Pilot (wrapper)

Catalogue reference: `docs/marketing/build_coo_service_catalogue.py`,
`packages()`. Typical buyer: place and ICB neighbourhood boards. Typical
timeline: 8-12 weeks for a place pilot design and measures. Described in
the catalogue as "an honest adjacency offer", not a Neighbourhood Health
delivery module.

This is a summary for the buyer conversation. For the step-by-step content,
open the linked module file -- do not restate its steps here.

## What this package bundles

| Module | Role in this package | Playbook / outline |
|---|---|---|
| E7 | Neighbourhood diversion design -- workshop, outcome list, non-scope register | [PB-E7-neighbourhood-diversion.md](PB-E7-neighbourhood-diversion.md) |

## Outcome for the place / ICB board

An agreed diversion outcome set, measured community-first options, no
over-claiming of product scope, and a link into wider neighbourhood plans.

## Sequencing note

This package depends on Module E1 already being in flight (or complete) at
the relevant provider -- diversion routes come from SPoA outcomes, so there
needs to be an SPoA operating model to divert *from*.

## Non-negotiable across this package

LEO does not provide urgent community response booking, virtual ward
capacity management, ambulance stack tools, Integrated Neighbourhood Team
case management, or social care records. State this explicitly at the start
of every Package D conversation, not as a footnote.
