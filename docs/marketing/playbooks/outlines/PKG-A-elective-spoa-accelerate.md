# Package A -- Elective SPoA Accelerate (wrapper)

Catalogue reference: `docs/marketing/build_coo_service_catalogue.py`,
`packages()`. Typical buyer: acute provider or provider-group Chief
Operating Officer. Typical timeline: 12-20 weeks for a first specialty
wave, then scale.

This is a summary for the buyer conversation. For the step-by-step content,
open the linked module files -- do not restate their steps here.

## Outcome for the COO

A pilot specialty live with clinician confirmation on every AI proposal,
write-back only after human review (where contracted), a board-ready
benefits baseline, and a plan to retire RAS-style workarounds for that
specialty.

## Sequencing note

E0 must complete before E1/E3/E4 start (it picks the specialty and informs
the guideline scope). E8 should run in parallel with E3/E4, not after them
-- clinical safety and installation checks are cheaper to fix early. E9's
baseline capture must happen before the pilot goes live, not after.

## Non-negotiable across every module in this package

All AI outputs are advisory. A clinician confirms before any clinical
action or write-back. This is not adjustable per customer.
