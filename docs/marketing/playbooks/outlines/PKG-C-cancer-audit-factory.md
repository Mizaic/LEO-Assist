# Package C -- Cancer Audit Factory (wrapper)

Catalogue reference: `docs/marketing/build_coo_service_catalogue.py`,
`packages()`. Typical buyer: Cancer Alliance and ICB leaders accountable
for earlier diagnosis and pathway standards. Typical timeline: 16-24 weeks
to a steady audit rhythm.

This is a summary for the buyer conversation. For the step-by-step content,
open the linked module files -- do not restate their steps here.

## What this package bundles

| Module | Role in this package | Playbook / outline |
|---|---|---|
| E5 | Cancer / NCDA mobilisation -- milestones, Alliance reporting, safety-netting | [PB-E5-ncda-mobilisation.md](PB-E5-ncda-mobilisation.md) |
| E6 | Coding operations -- human-in-the-loop review rhythm and learning loop | [PB-E6-coding-operations.md](PB-E6-coding-operations.md) |
| E9 | Benefits and evaluation -- Faster Diagnosis Standard and data-quality measures | [PB-E9-benefits-evaluation.md](PB-E9-benefits-evaluation.md) |

## Outcome for the Alliance / ICB leader

Live pathway dashboards for leaders, actioned safety-netting queues, a
coding quality loop with gold labels, and clear Faster Diagnosis Standard
insight.

## Sequencing note

E5 (pathway/milestone/safety-netting) and E6 (coding operations) run in
parallel once programme setup is agreed -- they share the same underlying
coded-encounter data but have different reviewer audiences (auditors and
referral supervisors for E5; clinical coders for E6). Set the E9 metric set
before the first reporting cycle so Alliance-level reports are consistent
from month one.

## Non-negotiable across every module in this package

All AI outputs are advisory and reviewed by a human before they count as
audit data. This programme does not drive real-time individual treatment
decisions.
