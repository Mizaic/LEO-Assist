# Package B -- ICB Advice and Guidance Maturity (wrapper)

Catalogue reference: `docs/marketing/build_coo_service_catalogue.py`,
`packages()`. Typical buyer: ICB elective care and primary care leaders
working with provider COOs. Typical timeline: 8-16 weeks for system
baseline and first delivery wave.

This is a summary for the buyer conversation. For the step-by-step content,
open the linked module files -- do not restate their steps here.

| Module | Role in this package | Playbook / outline |
|---|---|---|
| E2 | Advice and Guidance acceleration -- maturity baseline and specialty rollout | [PB-E2-ag-acceleration.md](PB-E2-ag-acceleration.md) |
| E4 | Pathway and guideline factory -- underpins any specialty added to the rollout | [../playbooks/PB-E4-pathway-guideline-factory.md](../playbooks/PB-E4-pathway-guideline-factory.md) |

## Outcome for the COO / ICB lead

A shared maturity score and action plan against the national A&G
operational delivery framework, fewer avoidable outpatient first
appointments, clearer specialist advice back to primary care, and an
evidence pack for ICB assurance.

## Sequencing note

Run the E2 maturity baseline first -- it determines which specialties need
E4 pathway/guideline work before rollout can proceed. E9's metric set
should be agreed alongside the E2 baseline, not bolted on afterwards.

## Non-negotiable across every module in this package

All AI outputs are advisory. A clinician confirms before any clinical
action or write-back. This is not adjustable per customer.
